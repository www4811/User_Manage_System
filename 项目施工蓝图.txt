用户管理系统 - 施工蓝图
========================

第一步：pom.xml 新增依赖
-----------------------
在现有的 <dependencies> 里追加：

<!-- JWT -->
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-api</artifactId>
    <version>0.12.6</version>
</dependency>
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-impl</artifactId>
    <version>0.12.6</version>
    <scope>runtime</scope>
</dependency>
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-jackson</artifactId>
    <version>0.12.6</version>
    <scope>runtime</scope>
</dependency>
<!-- 参数校验 -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-validation</artifactId>
</dependency>


第二步：配置 application.properties
-------------------------------------
spring.application.name=User_Manage_System

# MySQL
spring.datasource.url=jdbc:mysql://localhost:3306/user_manage_system?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf-8
spring.datasource.username=root
spring.datasource.password=root
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# JWT（secret改成你自己的任意长字符串，别用默认的）
jwt.secret=你的密钥（换成任意长字符串）
jwt.expiration=86400000


第三步：数据库建表 SQL
-----------------------
先手动在MySQL创建数据库 user_manage_system（字符集 utf8mb4），然后执行：

CREATE TABLE sys_role (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    role_name VARCHAR(50) NOT NULL,
    role_code VARCHAR(50) NOT NULL UNIQUE,
    description VARCHAR(255),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE sys_user (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    email VARCHAR(100),
    phone VARCHAR(20),
    status TINYINT DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE TABLE sys_user_role (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL,
    role_id BIGINT NOT NULL
);

核心逻辑要点提示
===============

UserRepository 关键点
---------------------
- 用 JdbcTemplate 操作数据库
- findAll 方法要支持分页（LIMIT ?, ?）和模糊搜索（WHERE username LIKE ?）
- 需要 RowMapper<User> 把 ResultSet 映射成 User 对象
- 查询总数用 SELECT COUNT(*)

UserServiceImpl 关键点
-----------------------
- 注册时：先查用户名是否已存在 → BCrypt加密密码 → 插入用户 → 分配"user"角色
- 登录时：查用户名 → BCrypt校验密码 → 查用户角色 → 生成JWT返回
- 修改用户时：不能直接改密码，密码修改单独处理
- 权限判断：从JWT中解析出userId和role，判断是否有权限操作

JwtUtil 关键点
--------------
- 生成token时把 userId 和 role 存入payload（Claims）
- 验证token时解析并返回Claims
- 过期时间从配置读取 @Value("${jwt.expiration}")

拦截器（WebConfig 中用）
------------------------
- 实现 HandlerInterceptor，从请求头 Authorization: Bearer xxx 取token
- 校验token，解析出用户信息存入 request.setAttribute
- Controller里通过 @RequestAttribute 获取当前用户


API 接口总览
============
方法   | 路径                    | 说明               | 权限
-------|-------------------------|--------------------|----------
POST   | /api/auth/register      | 自行注册，默认普通用户 | 无需登录
POST   | /api/auth/login         | 登录，返回JWT令牌     | 无需登录
GET    | /api/users              | 用户列表（分页+搜索）  | admin
GET    | /api/users/{id}         | 查看用户详情          | admin / 自己
POST   | /api/users              | 管理员新增用户        | admin
PUT    | /api/users/{id}         | 修改用户             | admin / 自己
DELETE | /api/users/{id}         | 删除用户             | admin
